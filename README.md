# PNGTuber (รุ่นทดลอง 0.1)

โปรแกรมสลับรูปตามเสียงพูด ลากรูป 4 ท่ามาวางได้เอง ปุ่มลัดทั้งเครื่อง (ไม่แย่งปุ่มจากเกม/OBS)

## วิธีที่ 1: ลองรันก่อน (ต้องลง Node.js 20 ขึ้นไป)
```
npm install
npm start
```

## วิธีที่ 2: สร้างไฟล์ .exe แจกเพื่อน
**ผ่าน GitHub (ไม่ต้องลงอะไรเพิ่ม):**
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (รวมโฟลเดอร์ `.github`)
2. แท็บ **Actions** → เลือก `build-windows` → **Run workflow**
3. รอ 3-5 นาที เปิดงานที่เสร็จแล้ว ดาวน์โหลดไฟล์ใน **Artifacts** จะได้ `PNGTuber-0.1.0.exe`

**บนเครื่องตัวเอง:** `npm install` แล้ว `npm run dist` ไฟล์อยู่ในโฟลเดอร์ `dist`

## ใช้กับ OBS
Window Capture เลือกหน้าต่าง PNGTuber แล้วใส่ฟิลเตอร์ Chroma Key สีเขียว (พื้นหลังค่าเริ่มต้นเป็นสีเขียวอยู่แล้ว)
กดปุ่มฟันเฟืองมุมขวาบน (ขยับเมาส์จะโผล่) เพื่อซ่อนแผงก่อนจับภาพ

## หมายเหตุ
- Windows อาจขึ้นเตือน "ไม่รู้จักผู้เผยแพร่" เพราะไฟล์ไม่มีใบรับรอง กด "ข้อมูลเพิ่มเติม → เรียกใช้อยู่ดี"
- รุ่นนี้รองรับ Windows ปุ่มลัดทั่วเครื่องบน Mac ต้องอนุญาต Accessibility
